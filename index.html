About

Backend .NET engineering for security and enterprise systems.

I am a .NET Backend Developer with 5+ years of experience. Backend architecture, API development, database design, and system integrations are my strongest areas.

My core stack includes C#, .NET, ASP.NET Core, ASP.NET Web API, Entity Framework, SQL Server, MongoDB, and SignalR. I structure backends with Clean Architecture, SOLID principles, and Dependency Injection so business rules stay isolated and new features are fast to add.

At MTI Holding, I was part of an 8-person team that delivered 10+ enterprise systems for security, monitoring, and operations. As a freelancer, I architected the Mandoobi sales management backend end-to-end within a 4-person team. I turn complex requirements into maintainable systems that connect desktop and mobile clients with clean APIs and well-designed databases.
